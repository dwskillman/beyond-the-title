# site/: employee-facing website (Milestone 3)

This folder will hold the static Beyond the Title website: `index.html`, `css/` and `js/`.
It reads `data/stories.json`, `data/people.json` and `data/teams.json` from the project folder,
and shows only stories where `published === true`.

Nothing is built here yet. Milestone 1 delivers the Content Builder (`../builder/builder.html`) first.
